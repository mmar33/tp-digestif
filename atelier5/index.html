Défi foie

Trois manches pour tester ce que vous savez du foie, d’après les cours d’anatomie du système digestif.

  1. Repères : touchez le lobe ou la structure demandée sur le foie de six espèces (chien, chat, lapin, porc, bœuf, cheval).
  2. Quiz : 8 questions, dont 2 sur la position du foie par rapport à la ligne médiane, puis la topographie, les ligaments, les vaisseaux et les voies biliaires.
  3. Qui suis-je ? : reconnaissez l’espèce à partir d’une description ou d’un schéma de son foie.

Comment se déroule l’atelier

  1. Mettez-vous en binôme et prenez un numéro.
  2. L’atelier se fait en 3 manches : deux manches « puzzle », puis une manche « Défi foie » sous forme de quiz.
  3. Puzzle : placez sur le contour les pièces des structures présentes chez l’espèce de votre poste, et mettez de côté celles qui n’existent pas chez elle.
  4. Entre les puzzles, votre puzzle est corrigé par un autre binôme, et vous corrigez celui d’un autre binôme. Votre puzzle 2 se fera ensuite sur l’animal suivant.
  5. Défi foie : il se lance tout seul sur votre tablette. Le score est pris en compte automatiquement : pas d’échange de tablettes pour cette manche.
  6. Chaque binôme obtient une note sur 20. L’application vous guide à chaque étape : suivez les consignes affichées.

Cette tablette reste celle de votre binôme : aux étapes de correction, vous la prêterez au binôme qui vous corrige.
